# UTSUKU – page « bientôt disponible »

Ouvre `index.html` dans un navigateur, aucune installation nécessaire.

À personnaliser dans `js/main.js` (en haut du fichier) :
- `LINKS` : tes liens Discord, Instagram, etc. (vide = bouton masqué)
- `FORM_ENDPOINT` : l’adresse qui reçoit les e-mails (Formspree, Getform, ton propre serveur…)

Les couleurs sont dans `css/style.css`, bloc `:root` tout en haut.
